# Keel

一款 MT7621 路由器（16MB 闪存 / 512MB 内存，OpenWrt 设备型号 `jdcloud,re-cp-02`）的 OpenWrt 固件项目：

- OpenWrt 25.12.5 为底，所有功能落在原生配置（uci / fw4 / dnsmasq / odhcpd / ddns-scripts）上，LuCI 里看得到、改得了；
- 一套网页管理界面，后端是 rpcd 的 ucode 插件 `kelapi`；
- 代理加速（mihomo）、广告过滤（AdGuardHome）、设备管理、IPv6 入站放行、一键升级；
- 「稳」是第一目标：代理或广告过滤出任何问题都会自动退回直连，不会让全家断网（守护脚本 + 独立看门狗）。

## 目录

| 路径 | 内容 |
|---|---|
| `后端插件/` | `kelapi`（全部后端接口）+ `kelapi.json`（权限）；`kelclash/`、`keladg/`（代理、广告过滤的守护脚本与默认配置）；`kel-lib/lib.sh`（两个守护共用）；`kel-watchdog`（看门狗）；`kel-upgrade`（升级程序）；`系统集成/`（设备策略、访客网络修复、厂商库、LuCI 菜单） |
| `前端静态包/kelweb.tar.gz` | 网页的唯一部署包。**不要手改**，由 `部署工具/打包前端.py` 生成 |
| `前端补丁/新增/` | 前端源文件：我们自己的页面、脚本、样式、图片，以及改过内容的页面（同名覆盖包里的） |
| `部署工具/` | `远程推送.sh`（日常推送）、`打包前端.py`、`检查定义顺序.py`（推送前的 ucode 检查，依赖 `ucode源码.py`）、`测试/`（在路由器上跑的只读检查） |
| `固件/` | 固件构建与升级：构建脚本、首次启动脚本、升级保留清单。说明见 [固件/README.md](固件/README.md) |

## 日常流程

```bash
# 1. 改代码（前端改 前端补丁/新增/ 里的文件）
uv run --no-project python 部署工具/打包前端.py     # 改了前端就要跑
git add -A && git commit -m "..."
# 2. 推到路由器（不碰网络、不重启服务；后端起不来会自动退回）
KEL_BIND=<物理网卡> ./部署工具/远程推送.sh <路由器地址> [后端|前端|全部]
# 3. 攒够改动后打固件、升级：见 固件/README.md
```

- 推送脚本只推**已提交**的内容，路由器上的代码 = 仓库的某个提交。
- 路由器上必须已经是这套命名的固件（有 `/etc/kel_version`），否则脚本会拒绝推送。
- 新增前端文件要登记进 `打包前端.py` 的 `EXTRA`，废弃的登记进 `REMOVED`。
- 新增带参数的后端方法要在 `kelapi` 末尾的参数声明区登记；只读方法登记进 `READ_ONLY`；页面要调用的方法加进 `kelapi.json`。

## 连接

- 如果电脑开着代理的虚拟网卡（TUN），SSH 要绑定物理网卡：`ssh -6 -B <网卡> root@<地址>`。
- 路由器的公网 IPv6 地址会随重拨变化，要用域名或定时上报来找。
- 看页面：`ssh -L '[::1]:18080:127.0.0.1:80' root@<地址>`，在路由器上 `ubus call session create` 开临时会话，把 `sessionid` 设成 cookie 后访问 `http://localhost:18080`，用完销毁会话。

## 硬约束

1. **会动网络的操作必须先确认**：wifi reload、改局域网地址、断拨号、重启、刷机都算。
2. 不绕过 OpenWrt：功能落在原生配置上；每个功能只有一个入口。
3. 不针对某个域名/设备单独处理，找一类问题的统一解法。
4. 改了 dhcp 配置要 `dnsmasq restart`，不能 reload（HUP 有竞态会把 dnsmasq 打死）。
5. 本机如果是 macOS（BSD 工具）：`grep "a\|b"` 是字面匹配，要写 `grep -E 'a|b'`；`sed -i` 要带空参数。
6. ucode：`/` 是整数除法；函数创建时就固化对外部变量的绑定（所以「定义在后、用在前」会出错，推送前有检查）；`int(null) === 0`，缺值要先判空。
7. 路由器的 busybox：`nc` 没有 `-w`，没有 `timeout`、`base64`、`diff`；探测用 `curl -m`。
8. 不要把密钥、路由器备份、个人配置提交进仓库（`.gitignore` 已列出）。
